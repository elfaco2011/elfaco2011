# Khalid El Fakir

Python tools for manufacturing companies: production data, automated reports and dashboards.

I've spent 10 years on industrial production lines — building, commissioning and
troubleshooting automated lines in Italy and abroad. Now I turn machine data,
production logs and Excel files into reports and dashboards people on the shop floor actually use.

## What I build
- Cleaning and merging production data (CSV, Excel, machine logs)
- Automated daily/weekly reports (Excel, PDF)
- Streamlit dashboards for downtime, cycle times and consumption
- Small automation tools: CSV processing, PDF and invoice generation
